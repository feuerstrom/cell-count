# Подсчёт клеток на камере Горяева

Калькулятор на одной странице для подсчёта клеток на камере Горяева с окраской трипановым синим. Считает концентрацию живых клеток (VCD), общую концентрацию (TCD) и выживаемость.

## Как пользоваться

1. Введите пары «живые мёртвые» для 10 групп по 4 больших квадрата, например `6 0, 5 1, 3 4 …`. Диктуйте с паузами: «шесть ноль, пять один». Можно диктовать кнопкой «🎤 Диктовать» (Chrome) или через микрофон на клавиатуре телефона. Числа распознаются и цифрами, и словами.
2. Проверьте таблицу L/D. Значения в ней можно исправить вручную.
3. Укажите разведение, включая краситель: суспензия + трипановый синий 1:1 = 2.
4. Получите результат. Кнопка «Скопировать результат» копирует таблицу и цифры текстом.

## Формулы

```
VCD       = ΣL × разведение × K              [×10⁶ кл/мл]
Viability = ΣL / (ΣL + ΣD) × 100             [%]
TCD       = (ΣL + ΣD) × разведение × K       [×10⁶ кл/мл]
```

VCD и TCD округляются до 2 знаков после запятой, выживаемость до 1 знака. Половина округляется вверх, расчёт ведётся с полной точностью.

K — коэффициент пересчёта: 1 / объём подсчёта. `K = 0,00625` ×10⁶ соответствует 40 большим квадратам (1,6·10⁻⁴ мл). Его можно изменить на странице.

## Проверки качества

Приложение предупреждает, если:
- заполнено меньше 10 групп;
- всего меньше 50 клеток (показывается погрешность ≈ 1/√N);
- в одной группе больше 200 клеток;
- разброс между группами слишком большой. Отклонившиеся группы подсвечиваются.

## Техническое

Один файл `index.html` без зависимостей и без сервера. Данные никуда не отправляются, в браузере запоминаются только разведение и коэффициент пересчёта. Встроенный голосовой ввод работает в Chrome по HTTPS (например, на GitHub Pages) и требует интернета.
